# Presentación del proyecto

El diagnóstico y tratamiento de enfermedades cardiovasculares requiere una identificación temprana de arritmias cardiacas. No obstante, el procedimiento convencional consiste en la revisión de un especialista, de uno a uno de los latidos del corazón registros en un electrocardiograma (ECG), lo que requiere una cantidad significateiva de tiempo y puede inducir a imprecisiones humanas.

Por tanto, en este proyecto se explora como una red LSTM con Mecanismos de Atención en conjunto con clasificador XGBoost se desempeña para esta labor, además los resultados obtenidos se compararán con otros métodos como son , para este ejercició se utilizará la base de datos [MIT-BIH Arrhythmia](https://www.physionet.org/content/mitdb/1.0.0/).

Este enfoque permitirá demostrar la eficiencia y el desempeño de las técnicas de ML híbridas en la identificación de arritmias y el potencial que tienen para el diagnóstico y el acompoñamiento en las decisiones médicas.
